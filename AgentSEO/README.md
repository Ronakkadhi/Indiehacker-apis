# AgentSEO REST API

Set the collection variable `AGENTSEO_API_KEY` to your own key in Requestly. The Search Results and Google AI Overview Evidence requests demonstrate SEO and answer engine optimization (AEO) workflows. Requests consume live credits. If a response is HTTP 202, use the returned polling URL with the same API key to get the result.
